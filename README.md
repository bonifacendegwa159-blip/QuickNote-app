# QuickNotes

QuickNotes is a simple browser-based note-taking application that allows users to create, organize, search, and delete notes. Notes can be assigned to Personal, Work, or Study categories, and they are saved in the browser using localStorage so they remain available after refreshing the page.

## Features

- Add notes
- Categorize notes as Personal, Work, or Study
- Delete notes
- Search notes
- Validate empty notes
- Limit notes to 200 characters
- Display the number of saved notes
- Save notes using localStorage
- Restore notes after refreshing the page
- Responsive layout for mobile screens

## How to Run Locally

1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

No additional installation or dependencies are required.
